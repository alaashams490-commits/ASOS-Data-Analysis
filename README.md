This project analyzes retail data from ASOS to identify business insights using Python. It specifically focuses on quantifying "phantom revenue loss" caused by stockouts across different brands.

Key Objectives
Data Cleaning: Handled missing values and optimized data types for pricing analysis.

Revenue Impact: Identified which brands are losing the most potential revenue due to inventory gaps.

Visualizations: Created scatter plots and charts using Seaborn and Matplotlib to show brand performance.

Tools Used
Language: Python

Libraries: Pandas, Seaborn, Matplotlib

Platform: Google Colab
